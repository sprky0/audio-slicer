Audio Slicer

Drop an audio file (WAV or MP3) here
or click to select

How to use

  1. Drop an audio file onto the box above
  2. Drag the red and green markers to set loop points
  3. Choose the number of slices from the dropdown
  4. Click SET to divide the selection into segments
  5. Use the Play button or API to play segments

API Example

// Play segments in sequence
const slicer = window.audioSlicer;
slicer.playSegment(0);  // Play first segment
slicer.getSegmentCount();  // Get total segments
